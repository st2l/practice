# stack-shellcode (CTF task)

Задание на утечку адреса стека и выполнение shellcode.

## 1) Уязвимость

Функция `leave_note` читает 300 байт в буфер 96 байт:

```c
char note[96];
read(0, note, 300);
```

Это даёт BOF и перезапись адреса возврата.

## 2) Утечка адреса

Адрес локального буфера печатается как «Clipboard address». Это адрес на стеке.

## 3) Защиты

Стек исполнимый (`-z execstack`), canary отключён. PIE выключен.

## 4) Как запускать

```bash
cd stack-shellcode
docker compose up --build -d
```

Сервис слушает `127.0.0.1:1337`.

## 5) Флаг

Флаг задаётся через `docker-compose.yml` переменной окружения `FLAG`.

## 6) Идея эксплуатации

1) Получить адрес буфера на стеке.
2) Поместить shellcode в буфер.
3) Перезаписать RIP адресом буфера и получить shell.

## 7) PoC

Есть примерный PoC: `solve.py`.

```bash
python3 solve.py HOST=127.0.0.1 PORT=1337
```
