# static-rop-leak (CTF task)

Мини-сервис с BOF и утечкой адреса бинаря. Бинарь статически линкован, так что ROP-цепочка собирается целиком из него.

## 1) Уязвимость

В пункте `2) Leave a review` есть чтение в фиксированный буфер:

```c
char buf[128];
read(0, buf, n); // n до 512
```

Что приводит к переполнению стека и перезаписи адреса возврата.

## 2) Утечка адреса

Пункт `1) Get session token` печатает «токен», который является обфусцированным адресом функции из `.text`.
При разворачивании обфускации получается реальный адрес в бинаре (PIE включён), что позволяет вычислить базу.

## 3) Как запускать

```bash
cd static-rop-leak
docker compose up --build -d
```

Сервис доступен на `127.0.0.1:1337`.

## 4) Флаг

Флаг задаётся через `docker-compose.yml` переменной окружения `FLAG`.

## 5) Идея эксплуатации

1) Получить токен, восстановить адрес функции и базу PIE.
2) Переполнением стека собрать ROP-цепочку для вызова `system("/bin/sh")`.
3) Забрать `flag.txt` из контейнера.

## 6) PoC

Есть примерный PoC: `solve.py`.

```bash
python3 solve.py HOST=127.0.0.1 PORT=1337
```
