# fmt-got (CTF task)

## 1) Небольшое описание уязвимости и почему она возникает

`Format string vulnerability` возникает, когда пользовательский ввод передается в `printf` как форматная строка:

```c
printf(motto);
```

Из-за этого атакующий может читать/писать память через форматные спецификаторы (`%p`, `%n`).

## 2) Способы защиты от уязвимости

- Никогда не передавать пользовательский ввод как формат: использовать `printf("%s", motto)`.
- Включать полную RELRO (`-Wl,-z,relro,-z,now`) для защиты GOT от перезаписи.
- Включать PIE/ASLR и другие hardening-флаги.
- Ограничивать и валидировать пользовательский ввод.

## 3) Как запускать приложение (с командами)

```bash
cd fmt-got
docker compose up --build -d
```

Проверка сервиса:

```bash
nc 127.0.0.1 1337
```

Остановка:

```bash
cd fmt-got
docker compose down
```

Флаг задаётся в `docker-compose.yml` переменной окружения `FLAG`.

## 4) Описание уязвимости в реализованном приложении

Эксплуатация строится на перезаписи записи `puts@GOT` в `system@plt` через `%n`, после чего строка `/bin/sh` передаётся в путь к вызову `puts(phrase)`. Так как PIE отключен, адреса в бинаре стабильны, что упрощает атаку.

## 5) PoC-эксплоит для получения флага

PoC: `solve.py`.

```bash
cd fmt-got
python3 solve.py HOST=127.0.0.1 PORT=1337
```

После получения shell:

```bash
cat flag.txt
```
