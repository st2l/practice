# fmt-got (CTF task)

Задание на format string с перезаписью `.got.plt` и последующим вызовом `system("/bin/sh")`.

## 1) Уязвимость

Пользовательский ввод попадает напрямую в `printf`:

```c
printf(motto);
```

Это позволяет использовать форматную строку для записи в память (`%n`).

## 2) Что нужно сделать

1) Перезаписать запись в GOT для `puts` на адрес `system@plt`.
2) Передать строку `/bin/sh`, которая будет аргументом для `system` при вызове `puts(phrase)`.

PIE выключен, так что адреса в бинаре фиксированные.

## 3) Как запускать

```bash
cd fmt-got
docker compose up --build -d
```

Сервис слушает `127.0.0.1:1337`.

## 4) Флаг

Флаг задаётся через `docker-compose.yml` переменной окружения `FLAG`.

## 5) PoC

Есть примерный PoC: `solve.py`.

```bash
python3 solve.py HOST=127.0.0.1 PORT=1337
```
